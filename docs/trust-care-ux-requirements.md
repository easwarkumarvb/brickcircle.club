# BrickCircle Trust & Care implementation

Implement in this branch; no merge/deploy/production modification.

1. Require three actual assembled-set photos (front, side, rear) before Available for Exchange, reusing gallery, not before adding a set. Existing legacy handling and lock safety must be preserved.
2. Show accessible lightweight dismissible appropriately capped nudges when adding a set, making it available, finding a match, arranging meetup and returning. Theme: Build with care. Share with honesty. Links to official LEGO instructions https://www.lego.com/en-in/service/building-instructions and replacement parts https://www.lego.com/en-in/service/replacement-parts. No promise of free parts.
3. At availability, simple owner self-report checked / known missing pieces / not checked, with optional missing parts description; unknown permitted, and never treat default 100 completeness as verified.
4. In initial and return mutual inspection flows, guide both parties to inspect assembled set, accessories, visible gaps and agreed three photos. Retain server-owned independent inspection/handoff safety confirmations and append-only audit records; snapshot accepted condition if safely feasible.
5. Focused tests, docs, mobile UX accessibility. Avoid cumbersome full inventory, admin arbitration, payment and wholesale rewrite. Use Opencode or Copilot for coding and Codex only for complex reasoning. Tests and review before PR. Do not merge or deploy.
